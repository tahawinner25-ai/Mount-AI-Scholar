  - Frontend React / Vite déployé avec une fiabilité maximale (Netlify).
  - API microservice backend Python / Gemma & Codex hébergée sur Google Cloud Run.
  - Application native Android (`.aab`) encapsulée via PWA Builder / Capacitor et publiée sur le Google Play Store.
- **La Machine de Conversion (Nas.com) :** 
  - Lancement des campagnes Magic Ads ciblées sur les parents d'élèves dyslexiques, les enseignants spécialisés et les orthophonistes.
- **La Métrique Or (500 WAU) :** 
  - Atteindre et verrouiller **500 utilisateurs actifs hebdomadaires**. Pour une Big Tech, 500 utilisateurs validant que l'IA locale et le mode saccadique accélèrent l'apprentissage et la lecture est la preuve clinique et scientifique de la valeur de l'algorithme.
